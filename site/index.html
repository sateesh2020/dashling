How it works.

Three pieces, and one rule: the container can only do what one short script allows.

  1. 1

    Your phone shows the panel

    A plain web page, installable on iPhone and iPad, plus a kiosk app for Android. It talks only to your container.

  2. 2

    The container does the fetching

    Weather, news and rates go through it, so the page itself never calls third parties. Feeds must be public https links.

  3. 3

    One script is the only door

    The container's SSH key can run exactly one script on your computer. It answers a fixed list of commands and refuses everything else.

Locked down by design.

  • ✓
    One command, one keyAn SSH key pinned to a single script. Every argument is validated, anything unknown is refused.
  • ✓
    Hardened containerRead-only filesystem, non-root user, all Linux capabilities dropped.
  • ✓
    Safe fetchingFeed links must be https and public. Your network and the host are off limits.
  • ✓
    Tested, not just claimedHostile input to the gates, path traversal and SSRF are covered by automated tests on every push.

Get started in minutes.

Run the published image (linux/amd64 and linux/arm64). The setup script gives the container a locked-down way to read your computer, and asks before changing anything.

git clone https://github.com/sateesh2020/dashling.git && cd dashling
./host/dashling.sh setup            # one time, asks first
HOST_SSH=$(whoami)@host.docker.internal docker compose up -d
docker compose logs -f dashling     # shows your pairing code

Then open http://<your-computer-ip>:8787 on your phone and enter the code. On Windows use host\windows\dashling.ps1 setup.

Download the signed APK from the latest release and open it on the phone. It updates in place, because every release is signed with the same key.

Download the Android app

Check the file against SHA256SUMS.txt on the release page. Signing certificate SHA-256: 21:F4:BD:B1:E7:4E:C3:5C:1D:A7:E7:AE:3A:4E:48:F3:3D:51:68:02:8F:B7:1C:25:92:CF:C6:6B:6A:5E:B8:26
